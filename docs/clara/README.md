# Historical Clara integration material

These files record contracts and manual deployment procedures from the period
when Sentinel research was integrated with a separate Clara workspace. They are
retained for archaeology and are not current operating instructions.

- [Migration checklist](MIGRATION.md) documents old host paths, schema changes,
  and manual commands. Its warnings and expected payloads are dated.
- [`sentinel/`](sentinel/) contains the old Clara-facing endpoint summaries.

The current research runtime, API, and deployment process are documented in
[AI pipeline](../ai-pipeline.md), [API reference](../api/README.md), and
[Deployment](../deployment.md).
